## Goal and evidence

Implement source-only adapters for the existing SwayNC notification owner and
Hyprsunset controller identified by approved Plan 148. Preserve original MIT
Omarchy v4.5.0 commit ac2690cd7be4f47e4a255f5e2e78d904d436b068 Dnd.qml,
NightLight.qml, Indicators.qml and BarIndicator.qml visuals/layout/dispatch, with

## Shape and gaps

A standard-library native helper uses only fixed root-owned clients, existing
unique D-Bus owners and a verified same-user Hyprsunset socket/process. No target
bus activation, daemon launch, GNOME-global preference or controller replacement.
A canonical user-bus connection can socket-activate that transport: DND requires
an explicit connection-risk flag and optional-widget visibility/query consent,
not an atomic no-activation claim. No native connection is made by this request. Status is
known/unknown, never an invented inactive value. Actions carry provider-scoped
native proof/state keys, revalidate before a single explicit setter, and read
back without retry or compensation. DND sets only its boolean; nightlight sets
only identity, preserving existing Kelvin/gamma/scheduling configuration.
Private before/prepared/outcome receipts preserve uncertainty and prevent silent
replay after interrupted operations; explicit acknowledgement performs no native
write. Restore is a separately reviewed fresh explicit state action, never an
automatic reset to a hardcoded temperature or GNOME preference.

One shared QML owner serves every output, with a bounded helper response and
explicit status refresh while the optional widget is enabled. A repeating status
refresh is not a component expiry: approved runtime remains session-lifetime.
Original DND/nightlight components are derived against provider interfaces;
unknown targets are not admitted into active/inactive blocks. Add the optional
fourteenth trusted bar Component and transactional Show/Hide Status Indicators
menu routes; keep the existing twelve defaults and user layout unchanged.
No arbitrary QML/service/command/plugin discovery or replacement panel.

## Safety and exclusions

Back up each affected path with existence/hash/mode, preserve dirty work, all old
vendor parents and the reference package. No native host probe/action in this
implementation request, installed-path/PID inspection, deployment/reload/restart,
packages/sources/services/agents, privilege, notification ownership takeover,
global GNOME settings, inhibitor/idle/lock/lid/suspend, reminder/recording/remote/
sudo/security policy, corporate-agent change, commit or publication. Installation,
optional visibility and native interaction acceptance remain distinct gates.
SwayNC's reviewed own-app GSettings dnd-state binding can persist a clicked DND
choice; receipts restore only its boolean, not unset/explicit key inheritance.
No raw/global dconf snapshot is collected. Native protocols are not atomic
compare-and-swap; owner changes after validation,
unobserved ABA, partial failures, IPC framing and readback limits stay explicit.
